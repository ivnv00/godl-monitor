# Official GODL artwork

Retrieved from GODL Supply's own website on 24 September 2026. These are the
actual published assets, not generated recreations. Original files and SHA256
values are recorded in [SOURCES.json](SOURCES.json).

- [Official wordmark](https://www.godl.supply/icons/logo.png): used unchanged in
  the sidebar at 132 × 44 and popup at 81 × 27 logical points.
- [Official G symbol](https://www.godl.supply/icons/godl.png): used as an
  18-point macOS template image in the menu bar. macOS applies the foreground
  color for legibility; the silhouette is preserved.
- [Official application icon](https://www.godl.supply/android-chrome-512x512.png):
  published in GODL's site.webmanifest; converted with macOS sips/iconutil into
  GODL.icns at 16–512 pixels. No artwork was redrawn or enlarged beyond source
  resolution.

Artwork is bundled locally. The app does not request branding from the network
at runtime. Packaging includes both the Swift resource bundle and CFBundleIconFile.
The app remains identified as a community-built, unofficial read-only monitor. GODL retains ownership
of its brand artwork.


Currency placement: the official G mark prefixes GODL quantities throughout the
native monitor, with explicit per-role sizes and baseline alignment. It is an
original-color image, independently loaded from the menu-bar template. Number
accessibility labels include GODL; the decorative mark is not a separate stop.

These assets are excluded from the source-code MIT grant. Public redistribution permission remains a release gate; see [NOTICE](../NOTICE).
